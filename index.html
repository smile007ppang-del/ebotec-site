Software

사람은 결정하고, 계산은 결정적으로

AI는 "무엇을 어떻게 깎을지", "로봇이 어느 자세로 갈지" 같은 판단 계층에만 들어갑니다. 경로 계산과 실시간 제어는 끝까지 결정적(deterministic) 코드가 맡습니다. 검증 가능해야 현장에 쓸 수 있기 때문입니다.

EBO-SOFT · AI CAM

AI CAM 자동화 소프트웨어

CAD 모델을 읽어 feature(피처)를 인식하고, roughing(러핑) · finishing(피니싱) 전략과 tool engagement(툴 인게이지먼트), chip load(칩 로드)를 AI가 제안합니다. 확정된 전략은 결정적 toolpath(툴패스) 엔진이 계산하고, 드라이브에서 올라온 실제 절삭 데이터로 다음 제안이 다시 좋아집니다.

  • Design → Machine → Verify → Post 4단계 워크스페이스
  • Part → Feature → Strategy 3계층 구조, AI는 Strategy 선택에만 관여
  • adaptive clearing(어댑티브 클리어링) · trochoidal(트로코이달) 등 HSM 전략 내장
  • 서보 부하 실측 기반 G-code 이송 속도 자동 최적화
