ROBOT

6축 다관절 로봇 제어

관절 6개에 서보 6축. 작업 좌표에서 관절 각도까지 역기구학을 제어기 안에서 풀고, EtherCAT 주기마다 동기 명령을 내립니다.

  • 6축 IK · FK, 특이점 회피, 관절 한계 처리
  • 로봇 좌표 자동 생성 소프트웨어 (작업 → 관절 경로)
  • CiA402 규격 축 제어, 1 ms 이하 주기
5-AXIS CNC

5축 3차원 가공 기술

trunnion(트러니언) A·B 회전축과 X·Y·Z 직선축의 simultaneous(사이멀테이니어스) 5축 제어. 보간·look-ahead·가감속을 직접 구현합니다.

  • BA-TRT trunnion(트러니언) 기구학, 횡형 spindle(스핀들)
  • G-code 파싱 → IK → 미세 보간까지 자체 제어기
  • 알루미늄 구조 부품 단납기 가공에 최적화
SERVO & CONTROLLER

서보 드라이브 · 모션 제어기

DSP 기반 AC 서보 드라이브와 EtherCAT 마스터 제어기를 자체 설계합니다. 전류 루프부터 버스 동기까지 한 팀이 튜닝합니다.

  • FOC · SVPWM, 20 kHz 전류 루프, ΣΔ 절연 전류 센싱

Software

사람은 결정하고, 계산은 결정적으로

AI는 "무엇을 어떻게 깎을지", "로봇이 어느 자세로 갈지" 같은 판단 계층에만 들어갑니다. 경로 계산과 실시간 제어는 끝까지 결정적(deterministic) 코드가 맡습니다.

EBO-SOFT · AI CAM

AI CAM 자동화 지능형 소프트웨어

CAD 모델을 읽어 feature(피처)를 인식하고, roughing(러핑) · finishing(피니싱) 전략과 tool engagement(툴 인게이지먼트), chip load(칩 로드)를 AI가 제안합니다. 확정된 전략은 결정적 toolpath(툴패스) 엔진이 계산하고, 드라이브에서 올라온 실제 절삭 데이터로 다음 제안이 다시 좋아집니다.

  • Design → Machine → Verify → Post 4단계 워크스페이스
  • Part → Feature → Strategy 3계층, AI는 Strategy 선택에만 관여
  • adaptive clearing(어댑티브 클리어링) · trochoidal(트로코이달) 등 HSM 전략 내장
  • 서보 부하 실측 기반 G-code 이송 속도 자동 최적화
